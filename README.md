# HR Dashboard | Power BI Project

## Overview
This project is an interactive HR Analytics Dashboard developed using Power BI to analyze employee data, salary distribution, education qualifications, gender diversity, and job roles within an organization. The dashboard helps visualize workforce insights and supports HR decision-making through data-driven analysis.

## Features
- Employee count analysis by job title
- Gender distribution tracking
- Salary analysis by education qualification
- Education qualification analysis by job role
- HR KPI monitoring
- Interactive filters and visualizations

## Dashboard Highlights
- Total Employee Count: 16
- Gender-based workforce analysis
- Salary distribution across job titles
- Education qualification insights
- HR performance visualization

## Visualizations Included
- Bar Charts
- Donut Charts
- Pie Charts
- KPI Cards
- Line Charts
- Interactive Filters

## Tools & Technologies
- Power BI
- Excel / CSV Dataset
- Data Visualization
- Business Intelligence
- HR Analytics

## Business Insights
- Sales Representatives and Chocolatiers had the highest employee count
- Bachelor's Degree was the most common education qualification
- Salary trends varied based on education level and job title
- Gender distribution analysis provided workforce diversity insights
